# Governance

OpenSoftware maintains the project and its security and release policies. Maintainers merge changes
by reviewed pull request after required checks pass. CODEOWNERS identifies the current reviewers.

Compatibility, privacy guarantees, billing integrity, and fail-closed behavior take priority over
convenience. Significant changes should begin with a public issue or design proposal. Security
responses may be developed privately until coordinated disclosure is safe.

Maintainers may change as the contributor community grows. This document and CODEOWNERS are the
authoritative public record of project decision-making roles.
