# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Search existing issues first and include the smallest safe reproduction, the commit or release, and your deployment type.

Do not post API keys, prompts, completions, account data, production logs, private URLs, or other sensitive information. Maintainers may close support requests that cannot be investigated safely in public.

Suspected vulnerabilities must follow the private process in [SECURITY.md](SECURITY.md). Questions about third-party provider accounts, model licenses, cloud billing, and modified deployments should go to the relevant provider or operator.
