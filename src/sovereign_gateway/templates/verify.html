Independent verification

Verify OpenSoftware API

Inspect the API source and request fresh, nonce-bound hardware evidence without trusting June or Chat.

1. Inspect the source

The gateway implementation and deployment configuration are public at github.com/open-software-network/os-api.

2. Request fresh evidence

Choose your own random nonce, request an attestation token, verify Google's signature, and confirm the token contains your nonce, the expected audience, Intel TDX hardware, debug-disabled status, and the running image digest.

NONCE=$(openssl rand -hex 16)
curl -sS https://api.opensoftware.co/v1/gateway/attestation \
  -H 'content-type: application/json' \
  -d "{\"nonce\":\"$NONCE\"}"

What this supports

The evidence supports a narrower claim: Google attested the reported API workload identity on Intel TDX for your fresh nonce. It does not prove that every model provider is private or that the public source was reproduced byte for byte. API responses separately report the selected privacy class and backend.
