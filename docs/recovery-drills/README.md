# Recovery drills

Run recovery exercises in an isolated project using synthetic data. Keep the detailed drill
record—including project identifiers, IP addresses, revision names, secret versions, and raw
provider evidence—in a restricted operational system rather than this public repository.

Public summaries should record only the control tested, pass/fail result, remediation, and the
date the control must be exercised again. The procedures and expected invariants are documented
in [operations](../operations.md).
